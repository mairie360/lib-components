# Shared navigation — MAIR-548

Figma: [Navigation & Shell › AppShell](https://www.figma.com/design/T7vetUfuzPEXk5TxjHRiO2/Mairie360-%E2%80%93-lib-components?node-id=10-277) and [DesktopNavigation (Repos / Survol)](https://www.figma.com/design/T7vetUfuzPEXk5TxjHRiO2/Mairie360-%E2%80%93-lib-components?node-id=8-306).

`AccessibleShell` (and `AppShell` with `collapsibleSidebar`) lays the page out as the Figma AppShell: the desktop navigation next to a column holding the header and the module. The module area (`main`) fills the free space without margin and is the only scrolling region. The footer is no longer part of the page base (MAIR-1092): `showFooter` (false by default) adds the full-width footer below that row.

On desktop (≥ 1024 px, theme `body.mairie-ui`), `DesktopNavigation` rests collapsed at 72 px (logo and module icons). It opens to 248 px in 280 ms (`--mairie-ease-standard`), the labels fading in with a 90 ms delay, while the pointer is over it or keyboard focus is inside it (`data-expanded`, `:has(:focus-visible)`: a click does not keep it open), pushing the module aside instead of covering it. Transitions are removed with `prefers-reduced-motion`. Commands are at least 42 px high, 16 px text, 20 px icons; every command keeps its accessible name while collapsed (« Messagerie 4 à traiter » with a counter). Widths and text sizes are in rem (4.5rem / 15.5rem, 72 / 248 px at the default text size) and a command grows with its label (`min-height`, wrapping), so doubled text (RGAA 10.4) and the WCAG text spacing (10.12) cut nothing; while the band rests, labels and commune are visually hidden rather than overflowing it. The shell's `commune` prop is the single source of the commune: it shows « Commune de » and the name next to the logo, and « Mairie de » and the name in the header; without it, `sidebarProps.brandLabel` then `headerProps.commune` are used as fallbacks, and when none of the three is set neither place shows a commune (no placeholder name). The logo always comes from the library: `sidebarProps.brandLogoSrc` is ignored by the shell, so every front shows the same header. Each destination animates its icon on hover or keyboard focus (MAIR-1093, 400 ms, `--mairie-ease-spring`, keyed by `data-nav-anim`, none under reduced motion); an item picks another one, or `none`, with `animation`. Counters (`count`, or a numeric legacy `badge`) use `Counter` (MAIR-1094), on the corner of the icon while the band rests.

There is no collapse button and no tooltip any more. `sidebarCookieDomain` and the `sidebar-preference` exports stay accepted for compatibility but no preference is written or read. `onCollapsedChange` reports `true` at rest and `false` while expanded.

Below 1024 px the mobile drawer keeps its behaviour (focus kept inside, Escape, focus returned to the menu button). While the drawer, a dialog or the notification centre is open, the desktop navigation, content and footer are inert.

Colours (MAIR-1092, lib 2.3): the band and the header sit on the white frame (`--mairie-shell-background`, `--mairie-shell-border` rule); the active destination gets `--mairie-navigation-active-background` and a 3 px `--mairie-navigation-active-indicator` bar on the edge of the band. The Administration entry is styled like the other destinations (no red any more), and Workflows is no longer a default destination. The header shows « Mairie de <commune> » left of the search (`showCommune`, `commune`, MAIR-1109) and, with `showDate`, the date at the start of its right zone.

`layout="focus"` (MAIR-1139) drops the navigation and the header for a focused task: `bar` (64 px), `aside` (300 px table of contents named « Sommaire », folded behind a « Sommaire » button below 900 px), `content` (or `children`) and a sticky `footer` of actions, in that reading order, with one `main`; Escape never leaves the page. `AccessibleShell` takes `backdrop="ribbons"` (MAIR-1103) to draw `PublicBackdrop` behind the content of a public page; the shell cannot tell a public page, so the default is `none`.

Tests: `DesktopNavigationRuntime`, `AppShellRuntime`, `AppShellSkipNavigation` (behaviour) and `ShellLayoutCss` (expansion, reduced motion, footer and module rules of the theme, teal frame), `NavigationContrast` and `ThemeContrast` (rendered contrasts).
